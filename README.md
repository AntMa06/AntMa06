## 🚀 Featured Project / 代表性项目

### 基于机器学习的村镇建筑多灾害韧性快速评估系统
**国家级大创项目 · 负责人**

- 面向地震、风、洪多灾害耦合情景，构建村镇低多层建筑韧性的快速评估框架
- 基于剪切层简化模型的参数化批量样本生成 + 机器学习代理模型（Surrogate Model），
  将单栋建筑评估耗时从传统有限元的小时级压缩至秒级
- 技术栈：`Python` `scikit-learn` `Streamlit` `Pandas` `NumPy`
- 成果规划：学术论文 + 发明专利 + 软件著作权（专利在申，代码与数据暂不开源）
